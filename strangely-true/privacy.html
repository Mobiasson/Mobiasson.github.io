Privacy Policy

Last updated: September 30, 2026

Who this covers

Strangely True Uploader is used only by the owner of the Strangely True channel to publish videos to their own TikTok account. It has no other users.

What data it uses

When the owner logs in with TikTok, the tool receives:

  • an access token and refresh token, so it can post on the owner's behalf;
  • basic account info (display name and account ID), to show which account is connected.

It uses the user.info.basic and video.publish permissions only.

Where the data is kept

Tokens are stored only on the owner's own computer. They are not sent to any server other than TikTok's, not sold, and not shared with anyone.

Data about other people

The tool does not collect, read or store any information about viewers, followers or any other TikTok users.

Removing access

The owner can disconnect the tool at any time in the TikTok app (Settings and privacy, then Security, then Manage app permissions) and by deleting the stored token file.

Changes

This policy may be updated at any time. The latest version is always on this page.
